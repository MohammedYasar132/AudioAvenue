# Audio Avenue – Music Player Interface

Audio Avenue is a **modern music streaming interface built using HTML and CSS** that replicates the layout and user experience of a contemporary music application.

The project focuses on **frontend UI development, responsive layouts, and clean design systems**.

It demonstrates how to build a visually appealing music platform interface using modern web design techniques.

---

# 🚀 Features

## 🎵 Music Application Interface

The interface includes components typically found in modern music platforms:

* Sidebar navigation
* Playlist section
* Album cards
* Music player bar

---

## 📱 Responsive Design

The application layout adapts to different screen sizes and provides a clean and structured UI for music browsing.

---

## 🎨 Modern UI Components

The interface includes:

* Navigation sidebar
* Music library
* Playlist display
* Album artwork cards
* Music player controls

---

## 🖼️ Album Artwork Display

Albums and playlists display artwork with interactive hover effects and visual styling.

---

## 🎧 Music Player Section

The interface includes a player bar that displays:

* Track information
* Playback controls
* Progress bar
* Volume control

---

# 🏗️ Tech Stack

Frontend Technologies:
